## Abstract

로봇이 쓸모 있으려면 실험실 밖 현실 세계에서 실제로 필요한 작업을 해내야 한다. 비전-언어-행동(vision-language-action, VLA) 모델은 종단간(end-to-end) 로봇 제어에서 인상적인 결과를 보여 왔지만, 이런 모델이 통제되지 않은 실제 환경에서 얼마나 멀리 일반화할 수 있는지는 아직 열린 문제다. 본 논문은 {{< katex >}}\pi_0{{< /katex >}}를 기반으로 한 새 모델 {{< katex >}}\pi_{0.5}{{< /katex >}}를 소개한다. {{< katex >}}\pi_{0.5}{{< /katex >}}는 성격이 서로 다른 여러 작업을 함께 학습하는 공동 학습(co-training)으로 폭넓은 일반화를 얻는다. {{< katex >}}\pi_{0.5}{{< /katex >}}는 여러 로봇의 데이터, 상위 수준 의미 예측, 웹 데이터 등 다양한 출처를 활용해, 현실 세계에서 폭넓게 일반화되는 로봇 조작을 가능하게 한다. 이 시스템은 공동 학습과 함께, 여러 모달리티를 섞은 혼합 예제를 쓴다. 한 예제 안에 이미지 관측, 언어 명령, 물체 검출, 의미 수준의 하위 작업 예측, 저수준 행동이 함께 들어 있는 식이다. 실험 결과, 이런 지식 전이가 효과적인 일반화에 필수적임을 확인했다. 또한 종단간 학습 기반 로봇 시스템이 완전히 새로운 집에서 주방이나 침실 청소처럼 길고 손재주가 필요한 조작 작업을 해낼 수 있음을 처음으로 보인다.

> **역주.** *종단간(end-to-end) 제어*는 카메라 이미지 같은 원시 입력에서 로봇 명령까지를 사람이 설계한 중간 모듈(물체 인식, 경로 계획 등) 없이 하나의 학습된 모델이 직접 이어 주는 방식이다. *공동 학습*은 로봇 행동 데이터만이 아니라 웹 이미지 질의응답 같은 다른 종류의 데이터를 한 모델에 함께 섞어 학습하는 것을 말한다.

## 1 Introduction

**그림 2.** **새 주방을 청소하는 {{< katex >}}\pi_{0.5}{{< /katex >}}.** 로봇은 학습 데이터에 없던 집의 주방을 청소하라는 과제를 받는다. 모델에는 일반적인 작업(찬장 닫기, 물건을 서랍에 넣기, 엎지른 것 닦기, 그릇을 싱크대에 넣기)이 주어진다. 모델은 다음에 해야 할 하위 작업(예: 접시 집기)을 예측하는 동시에 저수준 행동을 출력하는 방식으로 이를 수행한다.

> *"Stuff your eyes with wonder... See the world. It's more fantastic than any dream made or paid for in factories."* — Ray Bradbury, *Fahrenheit 451*

개방형 세계 일반화(open-world generalization)는 물리 지능(physical intelligence) 분야에서 가장 큰 미해결 문제 중 하나다. 로봇 팔, 휴머노이드, 자율주행차 같은 체화(embodied) 시스템은 실험실을 벗어나 현실 세계의 다양한 상황과 예기치 못한 사건을 다룰 수 있을 때 비로소 진짜로 쓸모가 있다. 학습 기반 시스템은 폭넓은 일반화로 가는 길을 제시한다. 특히 최근에는 자연어 처리(Vaswani et al., 2017; Devlin et al., 2019; Brown et al., 2020; Touvron et al., 2023)에서 컴퓨터 비전(He et al., 2016; Radford et al., 2021; He et al., 2022; Kirillov et al., 2023)에 이르는 분야에서 규모를 키울수록 성능이 오르는 학습 시스템이 가능해졌다. 그러나 로봇이 현실에서 마주칠 상황은 너무 다양해서 규모만으로는 부족하다. 로봇이 여러 추상화 수준에서 일반화할 수 있을 만큼 폭넓은 지식을 주는 학습 레시피를 설계해야 한다. 예를 들어 이동형 로봇에게 처음 보는 주방을 치우라고 하면, 필요한 행동은 세 종류로 나뉜다. 어떤 행동은 데이터에 충분히 다양한 장면과 물체로 잘 담겨 있다면 쉽게 일반화된다(예: 칼이나 접시 집기). 어떤 행동은 기존 기술을 새로운 방식이나 새로운 순서로 쓰도록 고치거나 조정해야 할 수 있다. 또 어떤 행동은 사전 지식으로 장면의 의미를 이해해야 할 수 있다(예: 어느 서랍을 열어야 하는지, 조리대 위의 어떤 물건이 식기 건조대일 가능성이 가장 높은지). 이런 유연한 일반화를 가능하게 하려면 로봇 학습 시스템의 학습 레시피를 어떻게 구성해야 할까?

사람은 평생의 경험을 끌어와 이런 각각의 문제에 맞는 해법을 만들어 낸다. 이 경험이 모두 직접 겪은 것은 아니며, 모두 반복 연습에서 나온 것도 아니다. 예를 들어 우리는 남에게 들었거나 책에서 읽은 사실, 다른 맥락에서 수행한 다른 작업에서 얻은 통찰의 조각을 목표 분야에서의 직접 경험과 함께 쓴다. 이와 비슷하게, 일반화 가능한 로봇 학습 시스템도 다양한 정보 출처에서 경험과 지식을 옮겨 올 수 있어야 한다고 가설을 세울 수 있다. 이 출처 중 일부는 지금 하려는 작업과 직접 관련된 직접 경험이다. 일부는 다른 로봇 형태(embodiment), 다른 환경, 다른 분야에서 지식을 옮겨 와야 한다. 또 일부는 구두 지시(verbal instruction), 웹 데이터 기반 인식 작업, 상위 수준 의미 명령 예측처럼 데이터 종류 자체가 전혀 다르다. 이렇게 서로 다른 데이터 출처의 이질성은 큰 걸림돌이다. 다행히 최근의 비전-언어-행동(VLA) 모델은 이를 가능하게 하는 도구를 제공한다. VLA는 여러 모달리티를 같은 시퀀스 모델링 틀로 바꿔 놓기 때문에, 로봇 데이터, 언어 데이터, 컴퓨터 비전 작업, 그리고 이들을 조합한 데이터로 학습하도록 쉽게 맞출 수 있다.

본 논문은 이 관찰을 바탕으로, 이질적이고 다양한 지식 출처를 활용해 폭넓은 일반화를 이끌어 내는 VLA 공동 학습 프레임워크를 설계한다. {{< katex >}}\pi_0{{< /katex >}} VLA를 기반으로 여러 데이터 출처를 포함시켜 {{< katex >}}\pi_{0.5}{{< /katex >}} 모델(「파이 오 파이브」라고 읽는다)을 만든다. {{< katex >}}\pi_{0.5}{{< /katex >}}는 모바일 매니퓰레이터(mobile manipulator, 이동 베이스 위에 팔이 달린 로봇)를 제어해, 학습 중 한 번도 보지 못한 집에서도 다양한 가사 작업을 수행한다. {{< katex >}}\pi_{0.5}{{< /katex >}}는 여러 출처의 경험을 끌어온다. 다양한 실제 가정에서 모바일 매니퓰레이터로 직접 모은 중간 규모 데이터셋(약 400시간) 외에도 다음을 쓴다. 이동하지 않는 다른 로봇의 데이터, 실험실 조건에서 모은 관련 작업 데이터, 로봇 관측을 보고 「상위 수준」 의미 작업을 예측해야 하는 학습 예제, 사람 감독자가 로봇에게 준 구두 지시, 그리고 이미지 캡셔닝, 질의응답, 물체 위치 찾기 같은 웹 데이터 기반의 다양한 멀티모달 예제다(그림 1 참조). {{< katex >}}\pi_{0.5}{{< /katex >}}에 주어지는 학습 예제의 압도적 다수(첫 학습 단계에서 97.6%)는 가사 작업을 하는 모바일 매니퓰레이터가 아니라 다른 로봇이나 웹 데이터 같은 이런 다른 출처에서 나온다. 그럼에도 {{< katex >}}\pi_{0.5}{{< /katex >}}는 학습 중 보지 못한 완전히 새로운 집에서 모바일 매니퓰레이터를 제어할 수 있다. 수건 걸기나 침대 정리 같은 섬세한 작업을 수행하고, 상위 수준 프롬프트 하나만 받고 주방이나 침실 전체를 청소하는 10\~15분 길이의 장기 조작 작업을 해낸다.

{{< katex >}}\pi_{0.5}{{< /katex >}}의 설계는 단순한 계층 구조를 따른다. 먼저 이질적인 학습 작업 혼합으로 모델을 사전 학습한다. 그다음 모바일 조작에 특화하도록 파인튜닝하는데, 이때 저수준 행동 예제와 상위 수준 「의미」 행동을 함께 쓴다. 의미 행동이란 「도마 집기」나 「베개 정돈하기」 같은 하위 작업 레이블을 예측하는 것이다. 실행 중에는 추론의 매 단계마다 모델이 먼저 의미 수준의 하위 작업을 예측한다. 즉 작업 구조와 장면의 의미를 바탕으로 다음에 할 적절한 행동을 추론한다. 그런 다음 이 하위 작업을 바탕으로 저수준 로봇 행동 청크(action chunk, 여러 시점의 행동 묶음)를 예측한다. 이 단순한 구조로 두 가지를 얻는다. 하나는 장기 다단계 작업을 추론하는 능력이다. 다른 하나는 두 수준에서 서로 다른 지식 출처를 활용하는 능력이다. 저수준 행동 추론은 다른 로봇이 모은 행동 데이터(다른 환경의 더 단순한 고정형 로봇 포함)에서 쉽게 이득을 본다. 상위 수준 추론은 웹의 의미 예제, 상위 수준 주석 예측, 그리고 사람 「감독자」의 언어 명령에서 이득을 본다. 감독자는 방 청소 같은 복잡한 작업이 끝날 때까지, 다음에 할 하위 작업을 로봇에게 한 단계씩 말해 준다. 사람에게 일을 가르칠 때와 비슷한 방식이다. 이 설계는 그림 1에 나와 있다.

본 논문의 핵심 기여는 일반화 능력이 높은 VLA인 {{< katex >}}\pi_{0.5}{{< /katex >}}를 학습하는 시스템이다. 또한 적절히 다양한 데이터로 학습하면 이 모델에서 일반화가 나타날 수 있다는 개념 증명(proof of concept)을 함께 제시한다. {{< katex >}}\pi_{0.5}{{< /katex >}}의 일반화 능력과 각 공동 학습 요소의 중요성을 자세히 실험으로 평가한다. 저자들이 아는 한, 이 연구는 종단간 학습 기반 로봇 시스템이 완전히 새로운 집에서 주방이나 침실 청소 같은 길고 손재주가 필요한 조작 작업을 수행할 수 있음을 처음 보인 것이다. 실험과 비교를 통해, 이것이 다른 로봇, 상위 수준 의미 예측, 사람 감독자의 구두 지시, 웹 데이터 등 여러 출처에서 지식을 옮겨 왔기에 가능했다는 점도 보인다.

## 2 Related Work

**Generalist robot manipulation policies.** 로봇 조작 정책의 학습 데이터를 넓히면 두 가지 효과가 있다는 것이 최근 연구로 밝혀졌다. 즉 좁은 단일 작업 데이터셋 대신 여러 장면과 작업을 아우르는 다양한 데이터셋(Dasari et al., 2019; Ebert et al., 2021; Walke et al., 2023; Open X-Embodiment Collaboration et al., 2023; Khazatsky et al., 2024; Bharadhwaj et al., 2024; Fang et al., 2024; Shafiullah et al., 2023; AgiBot-World-Contributors et al., 2025)으로 학습하는 경우다. 그렇게 학습한 정책은 별도 조정 없이 더 넓은 범위의 작업을 풀 뿐 아니라, *새로운* 장면과 작업으로 일반화하는 능력도 좋아진다(Brohan et al., 2022; Open X-Embodiment Collaboration et al., 2023; Octo Model Team et al., 2024; Doshi et al., 2024). 이런 *범용(generalist)* 정책을 학습하려면, 흔히 수백 가지 작업과 장면에 걸친 데이터셋의 규모와 다양성을 감당할 새로운 모델링 방법이 필요하다. 비전-언어-행동 모델(VLA)(Driess et al., 2023; Zitkovich et al., 2023; Kim et al., 2024; Black et al., 2024; Wen et al., 2024; Zhen et al., 2024; Liu et al., 2024c; Li et al., 2024a; Belkhale and Sadigh, 2024; Szot et al., 2024; Pertsch et al., 2025; Team et al., 2025; Wen et al., 2025; Bjorck et al., 2025; Huang et al., 2025)은 매력적인 해법이다. VLA는 사전 학습된 비전-언어 모델을 로봇 제어용으로 파인튜닝하므로, 웹 규모 사전 학습에서 얻은 의미 지식을 로봇 문제에 활용할 수 있다. 플로 매칭(flow matching)(Black et al., 2024), 확산(diffusion)(Liu et al., 2024c; Wen et al., 2025; Liu et al., 2025), 또는 정교한 행동 토큰화 기법(Pertsch et al., 2025) 같은 표현력 높은 행동 디코딩 방식과 결합하면, VLA는 현실 세계에서 다양하고 복잡한 조작 작업을 수행할 수 있다. 그러나 언어 지시를 따르는 능력은 인상적이지만, VLA는 여전히 대개 학습 데이터와 아주 비슷한 환경에서 평가된다. 일부 연구는 물체 집기나 서랍 열기 같은 단순한 기술은 더 넓은 범위의 환경에서 로봇 데이터를 모으기만 해도 일반화시킬 수 있음을 시사한다(Chi et al., 2024; Shafiullah et al., 2023; Etukuru et al., 2024; Lin et al., 2024; Pertsch et al., 2025). 하지만 같은 방법을 주방 정리처럼 더 복잡하고 긴 작업에 적용하기는 어렵다. 이런 작업에서는 일어날 법한 상황을 로봇 데이터 수집량을 무작정 늘려 폭넓게 덮는 것이 불가능하기 때문이다. 본 논문의 실험에서는 학습 중 보지 못한 새 주방과 침실처럼 완전히 새로운 장면에서 {{< katex >}}\pi_{0.5}{{< /katex >}}를 평가한다. 그 결과 VLA가 대상 모바일 매니퓰레이터 플랫폼에서의 직접 경험뿐 아니라 다른 데이터 출처의 정보까지 활용해 완전히 새로운 장면으로 일반화할 수 있음을 보인다. 이 출처에는 다른(이동하지 않는) 로봇의 데이터, 상위 수준 의미 하위 작업 예측, 웹 데이터가 포함된다.

> **역주.** *정책(policy)*\ 은 관측을 받아 행동을 내놓는 함수(여기서는 신경망)를 말하는 강화학습·로봇 학습 용어다. *플로 매칭*과 *확산*은 모두 무작위 노이즈에서 출발해 조금씩 고쳐 가며 연속값 출력(여기서는 행동)을 만드는 생성 기법이고, *행동 토큰화*는 연속값 행동을 언어 토큰처럼 이산 기호로 바꿔 언어 모델과 같은 방식으로 예측하게 하는 방법이다.

**그림 3.** **모델 개요.** {{< katex >}}\pi_{0.5}{{< /katex >}}는 두 단계로 학습된다. 첫째, 사전 학습 단계에서는 서로 다른 데이터 출처를 모두 합쳐 이산 토큰을 쓰는 초기 VLA를 만든다. 이 단계에서는 다양한 로봇 플랫폼의 데이터, 상위 수준 의미 행동 예측, 웹 데이터를 쓴다. 로봇 데이터는 FAST 행동 토크나이저로 행동을 이산 토큰으로 표현한다(Pertsch et al., 2025). 둘째, 사후 학습 단계에서는 모바일 조작을 위한 저수준·상위 수준 추론에 맞게 모델을 특화한다. 이때 사람 감독자의 구두 지시를 포함해 작업과 가장 관련 깊은 데이터를 쓴다. 이 단계는 플로 매칭으로 행동 분포를 표현하므로, 효율적인 실시간 추론이 가능하고 세밀한 연속 행동 시퀀스를 표현할 수 있다. 추론 시에는 모델이 먼저 상위 수준 하위 작업을 추론한 뒤, 이 하위 작업을 바탕으로 행동을 예측한다.

**Non-robot data co-training.** 여러 선행 연구가 로봇 정책의 일반화를 높이려고 다양한 *비로봇* 데이터를 활용하려 했다. 선행 방법들은 컴퓨터 비전 데이터셋으로 비전 인코더를 초기화하거나(Xiao et al., 2022; Nair et al., 2022; Majumdar et al., 2023; Dasari et al., 2023), 이미 만들어진 작업 계획기(task planner)를 활용했다(Huang et al., 2022; Liang et al., 2023; Singh et al., 2023; Wang et al., 2024). VLA 정책은 보통 사전 학습된 비전-언어 모델에서 초기화되며, 이 모델은 대량의 인터넷 이미지·언어 데이터를 이미 학습한 상태다(Driess et al., 2023; Zitkovich et al., 2023; Kim et al., 2024). 눈여겨볼 점은 VLA 구조가 유연해서, 비전·언어·행동 토큰이 섞인 멀티모달 입력 시퀀스를 출력 시퀀스로 바꾸는 어떤 사상(mapping)도 학습할 수 있다는 것이다. 따라서 VLA는 단순한 가중치 초기화를 넘어 지식 전이 방법의 설계 공간을 넓힌다. 하나의 통합 구조를 로봇 행동 모방 데이터뿐 아니라, 앞서 말한 모달리티 중 하나 이상이 섞인 어떤 데이터셋으로도 *공동 학습*할 수 있기 때문이다. 선행 연구는 VLM 학습에 쓰는 데이터 혼합으로 VLA를 공동 학습하면(Driess et al., 2023; Zitkovich et al., 2023; Yang et al., 2025) 새로운 물체나 처음 보는 장면 배경을 다룰 때처럼 일반화 능력이 좋아질 수 있음을 보였다. 본 논문은 VLM 데이터 공동 학습을 넘어, 로봇과 관련된 더 넓은 지도 신호 출처로 VLA를 공동 학습하는 시스템을 설계한다. 여기에는 다른 로봇의 데이터, 상위 수준 의미 하위 작업 예측, 구두 지시가 포함된다. 다중 작업 학습과 공동 학습 자체는 새로운 아이디어가 아니다. 하지만 본 논문은 이 시스템의 특정한 데이터 출처 조합 덕분에 모바일 로봇이 완전히 새로운 환경에서 복잡하고 긴 행동을 수행할 수 있음을 보인다. 저자들은 작업의 복잡도까지 고려하면 이 수준의 일반화가 선행 연구에서 보인 결과를 크게 넘어선다고 본다.

**Robot reasoning and planning with language.** 여러 선행 연구는 종단간 정책에 상위 수준 추론을 더하면 긴 작업의 성능을 크게 높일 수 있음을 보였다(Ahn et al., 2022; Hu et al., 2023; Li et al., 2023; Stone et al., 2023; Shi et al., 2024; Belkhale et al., 2024; Dai et al., 2025; Chen et al., 2024; Liu et al., 2024b; Zawalski et al., 2024; Liu et al., 2024a; Nasiriany et al., 2024; Cheng et al., 2024; Shah et al., 2024; Zhi et al., 2024; Qiu et al., 2024; Shi et al., 2025; Li et al., 2025; Team et al., 2025; Zhao et al., 2025). 특히 상위 수준 하위 작업 추론이 사전 학습된 대규모 LLM과 VLM의 덕을 볼 수 있을 때 효과가 컸다. 본 논문의 방법도 두 단계 추론 절차를 쓴다. 먼저 상위 수준 의미 하위 작업(예: 「접시 집기」)을 추론하고, 그다음 이 하위 작업을 바탕으로 행동을 예측한다. 많은 선행 방법은 이를 위해 두 개의 별도 모델을 썼다. VLM이 의미 단계를 예측하고, 별도의 저수준 정책이 그 단계를 실행하는 식이다(Ahn et al., 2022; Shi et al., 2024; Cheng et al., 2024; Duan et al., 2024; Shah et al., 2024; Shi et al., 2025; Li et al., 2025). 본 논문의 방법은 상위 수준과 저수준 추론 모두에 완전히 같은 모델을 쓴다. 이 방식은 사고의 연쇄(chain-of-thought)(Wei et al., 2022)나 테스트 시점 연산(test-time compute)(Jaech et al., 2024) 방법에 더 가깝다. 다만 체화된 사고의 연쇄(embodied chain-of-thought) 방법들(Zawalski et al., 2024; Li et al., 2024b; Niu et al., 2024)과는 차이가 있다. 본 방법에서 상위 수준 추론은 사고의 연쇄 방식을 쓰면서도 저수준 행동 추론보다 낮은 빈도로 실행된다.

> **역주.** *사고의 연쇄*는 언어 모델이 최종 답 전에 중간 추론 단계를 글로 먼저 생성하게 하는 기법이고, *테스트 시점 연산*은 추론 시 연산을 더 들여(더 길게 생각하게 해) 성능을 높이는 방법을 가리킨다. 여기서는 모델이 행동 전에 하위 작업 문장을 먼저 생성하는 것을 이와 비슷한 구조로 본 것이다.

**Robotic learning systems with open-world generalization.** 대부분의 로봇 학습 시스템은 학습 데이터와 아주 비슷한 환경에서 평가되지만, 일부 선행 연구는 더 넓은 개방형 세계 일반화를 탐구했다. 로봇의 작업을 물체 집기 같은 좁은 기본 동작 집합으로 제한하면, 작업에 특화된 가정을 쓸 수 있다(예: 파지 예측, 모델 기반 계획·제어 도입). 이런 방법은 완전히 새로운 집까지 폭넓게 일반화함이 보고되었다(Jones, 2006; Dempsey, 2023; Nguyen and Kemp, 2014; Mahler et al., 2017; Fang et al., 2023). 그러나 이런 방법은 범용 로봇이 수행해야 할 수 있는 작업 전체로 쉽게 일반화되지 않는다. 더 최근에는 여러 분야에 걸쳐 모은 대규모 데이터셋(Khazatsky et al., 2024; Shah et al., 2023a; Open X-Embodiment Collaboration et al., 2023; Shafiullah et al., 2023; Chi et al., 2024; Lin et al., 2024)으로, 단순하지만 종단간으로 학습한 작업을 새로운 환경으로 일반화할 수 있음이 보고되었다(Gupta et al., 2018; Gervet et al., 2023; Shafiullah et al., 2023; Shah et al., 2023b; Ehsani et al., 2023; Lin et al., 2024; Etukuru et al., 2024; Pertsch et al., 2025). 하지만 이 시연들의 작업은 여전히 비교적 단순하다. 보통 1분이 채 걸리지 않고, 성공률도 비교적 낮은 경우가 많다. 본 논문은 {{< katex >}}\pi_{0.5}{{< /katex >}}가 새 침실 바닥의 옷을 모두 줍거나 그릇을 모두 싱크대에 넣는 것처럼 길고 여러 단계로 된 작업을 수행하면서, 완전히 새로운 집으로 일반화할 수 있음을 보인다.

## 3 Preliminaries

비전-언어-행동 모델(VLA)은 보통 다양한 로봇 시연 데이터셋 {{< katex >}}\mathcal{D}{{< /katex >}}에서 모방 학습(imitation learning)으로 학습된다. 관측 {{< katex >}}\mathbf{o}_t{{< /katex >}}와 자연어 작업 지시 {{< katex >}}\ell{{< /katex >}}이 주어졌을 때 행동 {{< katex >}}\mathbf{a}_t{{< /katex >}}(더 일반적으로는 행동 *청크* {{< katex >}}\mathbf{a}_{t:t+H}{{< /katex >}})의 로그 우도를 최대화하는 것이다: {{< katex >}}\max_\theta \mathbb{E}_{(\mathbf{a}_{t:t+H}, \mathbf{o}_t, \ell) \sim \mathcal{D}} \log \big(\pi_\theta(\mathbf{a}_{t:t+H} \vert \mathbf{o}_t, \ell)\big){{< /katex >}}. 즉 사람이 시연한 행동에 모델이 높은 확률을 주도록 학습한다. 관측에는 보통 이미지 하나 이상 {{< katex >}}\mathbf{I}^1_t, ..., \mathbf{I}^n_t{{< /katex >}}와 고유 감각 상태(proprioceptive state, 로봇 자신의 관절 위치 등) {{< katex >}}\mathbf{q}_t{{< /katex >}}가 들어 있다. VLA 구조는 현대 언어 모델과 비전-언어 모델의 설계를 따른다. 모달리티별 토크나이저가 입력과 출력을 이산(「하드」) 또는 연속(「소프트」) 토큰 표현으로 바꾸고, 커다란 자기회귀 트랜스포머 백본이 입력 토큰을 출력 토큰으로 바꾸도록 학습된다. 이 모델의 가중치는 사전 학습된 비전-언어 모델에서 초기화된다. 정책의 입력과 출력을 토큰 표현으로 바꾸면, 위의 모방 학습 문제는 관측·지시·행동 토큰 시퀀스에 대한 단순한 다음 토큰 예측 문제가 된다. 그러면 현대 머신러닝의 확장성 좋은 도구로 이를 최적화할 수 있다. 실제로 이미지와 텍스트 입력의 토크나이저는 현대 비전-언어 모델의 것을 그대로 따른다. 행동의 경우, 선행 연구가 압축 기반의 효과적인 토큰화 방법을 개발했으며(Pertsch et al., 2025), 본 논문은 사전 학습 동안 이를 쓴다. 최근 몇몇 VLA 모델은 확산(Liu et al., 2024c; Wen et al., 2025; Liu et al., 2025)이나 플로 매칭(Black et al., 2024)으로 행동 분포를 표현해, 연속값 행동 청크를 더 표현력 있게 나타내자고 제안했다. 본 모델의 사후 학습 단계에서는 플로 매칭으로 행동 분포를 표현하는 {{< katex >}}\pi_0{{< /katex >}} 모델(Black et al., 2024)의 설계를 기반으로 한다. 이 설계에서 행동 토큰의 입력은 아직 노이즈가 일부 남은 행동이다. 이 값은 플로 매칭의 직전 디노이징 단계에서 나온 것이다. 행동 토큰은 이를 받아 플로 매칭 벡터장을 출력한다. 이 토큰들은 별도의 모델 가중치 집합도 쓰는데, 전문가 혼합(mixture of experts) 구조에 빗대어 이를 「행동 전문가(action expert)」라고 부른다. 행동 전문가는 플로 매칭 기반 행동 생성에 특화될 수 있으며, LLM 백본의 나머지 부분보다 훨씬 작게 만들 수 있다.

> **역주.** *행동 청크* {{< katex >}}\mathbf{a}_{t:t+H}{{< /katex >}}는 현재 시점 {{< katex >}}t{{< /katex >}}부터 {{< katex >}}t+H{{< /katex >}}까지 여러 시점의 행동을 한 번에 예측한 묶음이다. 한 번의 추론으로 여러 스텝을 실행할 수 있어 제어가 매끄럽고 빠르다. 플로 매칭에서 모델은 순수 노이즈에서 시작해, 매 단계 「노이즈를 실제 행동 쪽으로 어느 방향으로 얼마나 옮길지」를 나타내는 벡터장을 예측하고 그 방향으로 조금씩 이동시켜 행동을 만든다.

## 4 The {{< katex >}}\pi_{0.5}{{< /katex >}} Model and Training Recipe

{{< katex >}}\pi_{0.5}{{< /katex >}} 모델과 학습 레시피의 개요는 그림 3에 있다. 모델 가중치는 웹 데이터로 학습한 표준 VLM에서 초기화한다. 이후 학습은 두 단계로 진행된다. 사전 학습 단계는 모델을 다양한 로봇 작업에 적응시키는 것이 목적이고, 사후 학습 단계는 모델을 모바일 조작에 특화하고 테스트 시점에 효율적으로 추론하는 장치를 갖추게 하는 것이 목적이다. 사전 학습 동안에는 로봇 행동이 있는 작업을 포함해 모든 작업을 이산 토큰으로 표현한다. 그러면 학습이 단순하고, 규모를 키우기 쉽고, 효율적이다(Pertsch et al., 2025). 사후 학습 동안에는 {{< katex >}}\pi_0{{< /katex >}}처럼 모델에 행동 전문가를 추가한다. 이는 행동을 더 세밀하게 표현하고, 실시간 제어를 위해 연산 효율이 더 좋은 추론을 하기 위해서다. 추론 시에는 모델이 먼저 로봇이 수행할 상위 수준 하위 작업을 생성하고, 이 하위 작업을 조건으로 행동 전문가를 통해 저수준 행동을 예측한다. 아래에서는 먼저 모델 구조를 설명하고, 이어서 각 학습 단계와 그 단계의 학습 작업을 설명한다.

### 4.1 The {{< katex >}}\pi_{0.5}{{< /katex >}} architecture

{{< katex >}}\pi_{0.5}{{< /katex >}} 구조는 행동 청크 분포와 토큰화된 텍스트 출력을 모두 유연하게 표현할 수 있다. 텍스트 출력은 공동 학습 작업(예: 질의응답)에도 쓰이고, 계층적 추론에서 상위 수준 하위 작업 예측을 출력하는 데도 쓰인다. 모델이 표현하는 분포는 {{< katex >}}\pi_\theta(\mathbf{a}_{t:t+H}, \hat{\ell} \vert \mathbf{o}_t, \ell){{< /katex >}}로 쓸 수 있다. 각 기호의 뜻은 다음과 같다. {{< katex >}}\mathbf{o}_t = [\mathbf{I}^1_t, ..., \mathbf{I}^n_t, \mathbf{q}_t]{{< /katex >}}는 모든 카메라의 이미지와 로봇의 자세(관절 각도, 그리퍼 자세, 몸통 리프트 자세, 베이스 속도)로 이루어진다. {{< katex >}}\ell{{< /katex >}}은 전체 작업 프롬프트(예: 「put away the dishes」)다. {{< katex >}}\hat{\ell}{{< /katex >}}은 모델의 (토큰화된) 텍스트 출력으로, 예측된 상위 수준 하위 작업(예: 「pick up the plate」)일 수도 있고 웹 데이터의 비전-언어 프롬프트에 대한 답일 수도 있다. {{< katex >}}\mathbf{a}_{t:t+H}{{< /katex >}}는 예측된 행동 청크다. 이 분포를 다음과 같이 분해한다.

{{< katex display=true >}}
\pi_\theta(\mathbf{a}_{t:t+H}, \hat{\ell} \vert \mathbf{o}_t, \ell) = \pi_\theta(\mathbf{a}_{t:t+H} \vert \mathbf{o}_t, \hat{\ell})\pi_\theta(\hat{\ell} \vert \mathbf{o}_t, \ell),
{{< /katex >}}

여기서 행동 분포는 {{< katex >}}\ell{{< /katex >}}에 의존하지 않고 {{< katex >}}\hat{\ell}{{< /katex >}}에만 의존한다. 따라서 상위 수준 추론은 {{< katex >}}\pi_\theta(\hat{\ell} \vert \mathbf{o}_t, \ell){{< /katex >}}를, 저수준 추론은 {{< katex >}}\pi_\theta(\mathbf{a}_{t:t+H} \vert \mathbf{o}_t, \hat{\ell}){{< /katex >}}를 나타내며, 두 분포 모두 같은 모델이 표현한다.

> **역주.** 즉 모델은 전체 작업(「설거지거리 치우기」)을 보고 먼저 지금 할 하위 작업 문장(「접시 집기」)을 만들고, 행동을 예측할 때는 원래 작업 문장이 아니라 이 하위 작업 문장만 본다. 같은 신경망이 이 두 확률을 모두 계산한다.

모델은 {{< katex >}}N{{< /katex >}}개의 멀티모달 입력 토큰 {{< katex >}}x_{1:N}{{< /katex >}}을 받아 멀티모달 출력 시퀀스 {{< katex >}}y_{1:N}{{< /katex >}}을 내는 트랜스포머에 해당한다(여기서 토큰이라는 말은 느슨하게, 이산 입력과 연속 입력을 모두 가리키는 뜻으로 쓴다). 이를 {{< katex >}}y_{1:N} = f\big(x_{1:N}, A(x_{1:N}), \rho(x_{1:N})\big){{< /katex >}}로 쓸 수 있다. 각 {{< katex >}}x_i{{< /katex >}}는 텍스트 토큰({{< katex >}}x_i^w\in\mathbb{N}{{< /katex >}}), 이미지 패치({{< katex >}}x_i^I\in\mathbb{R}^{p\times p \times 3}{{< /katex >}}), 또는 플로 매칭에서 로봇 행동의 중간 디노이징 값({{< katex >}}x_i^a\in\mathbb{R}^d{{< /katex >}})일 수 있다. 관측 {{< katex >}}\mathbf{o}_t{{< /katex >}}와 {{< katex >}}\ell{{< /katex >}}은 {{< katex >}}x_{1:N}{{< /katex >}}의 앞부분(prefix)을 이룬다. {{< katex >}}\rho(x_i){{< /katex >}}가 나타내는 토큰 종류에 따라, 각 토큰은 서로 다른 인코더로 처리될 뿐 아니라 트랜스포머 안에서도 서로 다른 전문가 가중치로 처리될 수 있다. 예를 들어 이미지 패치는 비전 인코더를 거치고, 텍스트 토큰은 임베딩 행렬로 임베딩된다. {{< katex >}}\pi_0{{< /katex >}}(Black et al., 2024)를 따라, 행동 토큰 {{< katex >}}x_i^a{{< /katex >}}는 트랜스포머 임베딩 공간으로 선형 사영하고, 트랜스포머 안에서 별도의 전문가 가중치로 처리한다. 어텐션 행렬 {{< katex >}}A(x_{1:N})\in[0,1]^{N\times N}{{< /katex >}}은 어떤 토큰이 다른 토큰에 어텐션할 수 있는지를 나타낸다. LLM의 표준 인과적(causal) 어텐션과 달리, 이미지 패치, 텍스트 프롬프트, 연속 행동 토큰은 양방향 어텐션을 쓴다.

모델은 텍스트(장면에 관한 질문에 답하거나 다음에 할 작업을 출력하기 위해)와 행동(세계에서 움직이기 위해)을 모두 출력해야 한다. 그래서 {{< katex >}}f{{< /katex >}}의 출력은 텍스트 토큰 로짓과 행동 출력 토큰 {{< katex >}}\big(y^\ell_{1:M}, y^a_{1:H}\big){{< /katex >}}로 나뉜다. 앞의 {{< katex >}}M{{< /katex >}}개는 {{< katex >}}\hat{\ell}{{< /katex >}}을 샘플링하는 데 쓰는 텍스트 토큰 로짓이다. 뒤의 {{< katex >}}H{{< /katex >}}개 토큰은 {{< katex >}}\pi_0{{< /katex >}}처럼 별도의 행동 전문가가 만들며, 선형 사상을 거쳐 연속 출력으로 바뀌고 {{< katex >}}\mathbf{a}_{t:t+H}{{< /katex >}}를 얻는 데 쓰인다(다음 절 참조). {{< katex >}}M + H \le N{{< /katex >}}이라는 점에 유의하라. 즉 출력 {{< katex >}}N{{< /katex >}}개 중 손실 계산에 쓰이는 것은 텍스트 로짓 {{< katex >}}M{{< /katex >}}개와 행동 출력 {{< katex >}}H{{< /katex >}}개뿐이며, 나머지 출력에는 손실이 붙지 않는다. 로봇의 고유 감각 상태는 이산화되어 텍스트 토큰으로 모델에 입력된다. 구조에 관한 자세한 내용은 부록 A.5에 있다.

### 4.2 Combining discrete & continuous action representations

**그림 4.** **사전 학습 및 사후 학습 작업의 예.** {{< katex >}}\pi_{0.5}{{< /katex >}}는 모바일 매니퓰레이터 데이터(`MM`), 다양한 환경의 이동하지 않는 로봇 데이터(`ME`), 실험실 조건에서 모은 교차 형태 데이터(`CE`), 상위 수준 하위 작업 예측(`HL`), 멀티모달 웹 데이터(`WD`)로 사전 학습된다. 사후 학습 단계에서는 구두 지시(`VI`)를 추가로 쓰고, 실험실 교차 형태 데이터(`CE`)는 빼서 모델이 모바일 조작과 다양한 환경에 집중하게 한다. 그림은 각 범주의 작업 중 일부를 예시로 보여 준다.

{{< katex >}}\pi_0{{< /katex >}}와 마찬가지로, 최종 모델에서는 플로 매칭(Lipman et al., 2022)으로 연속 행동을 예측한다. {{< katex >}}\mathbf{a}_{t:t+H}^{\tau, \omega} = \tau \mathbf{a}_{t:t+H} + (1-\tau)\omega{{< /katex >}}, {{< katex >}}\omega \sim \mathcal{N}(0,\mathbf{I}){{< /katex >}}라 하자. 여기서 {{< katex >}}\tau\in[0,1]{{< /katex >}}는 플로 매칭 시간 인덱스다. 모델은 플로 벡터장 {{< katex >}}\omega - \mathbf{a}_{t}{{< /katex >}}를 예측하도록 학습된다. 그러나 Pertsch et al. (2025)가 보였듯이, 행동을 이산 토큰으로 표현하면 VLA 학습이 훨씬 빨라질 수 있다. 특히 행동 청크를 효율적으로 압축하는 토큰화 방식(예: FAST)을 쓸 때 그렇다. 아쉽게도 이런 이산 표현은 실시간 추론에는 덜 적합하다. 추론 시 비용이 큰 자기회귀 디코딩이 필요하기 때문이다(Pertsch et al., 2025). 따라서 이상적인 모델 설계는 이산화된 행동으로 학습하면서도, 추론 시에는 플로 매칭으로 연속 행동을 만들 수 있어야 한다.

> **역주.** {{< katex >}}\mathbf{a}^{\tau,\omega}{{< /katex >}}는 실제 행동과 가우시안 노이즈 {{< katex >}}\omega{{< /katex >}}를 비율 {{< katex >}}\tau{{< /katex >}}로 섞은 값이다. 이 식대로라면 {{< katex >}}\tau=1{{< /katex >}}이 깨끗한 행동, {{< katex >}}\tau=0{{< /katex >}}이 순수 노이즈다. 회귀 목표 {{< katex >}}\omega - \mathbf{a}{{< /katex >}}는 이 직선 경로를 따라 노이즈 쪽으로 가는 방향이며, 추론 때는 그 반대 방향으로 적분해 노이즈에서 행동을 얻는다. 원문은 목표를 {{< katex >}}\omega - \mathbf{a}_{t}{{< /katex >}}로 썼지만 식 (1)에서는 청크 전체 {{< katex >}}\mathbf{a}_{t:t+H}{{< /katex >}}로 쓴다. *FAST*는 행동 청크를 주파수 영역 변환으로 압축한 뒤 토큰으로 바꾸는 행동 토크나이저다.

그래서 본 모델은 행동을 *두 가지 방식으로 모두* 예측하도록 학습된다. 하나는 (FAST 토크나이저를 써서) 토큰을 자기회귀로 샘플링하는 방식이고, 다른 하나는 플로 벡터장을 반복 적분하는 방식이다. 이렇게 두 방식의 장점을 모두 취한다. 어텐션 행렬을 이용해, 서로 다른 행동 표현이 서로에게 어텐션하지 않도록 한다. 모델은 다음 결합 손실을 최소화하도록 최적화된다.

{{< katex display=true >}}
\begin{aligned}
\mathbb{E}_{\mathcal{D}, \tau, \omega} \Big[&\ H\big(x_{1:M}, f^\ell_\theta(\mathbf{o}_t, \ell)\big) \\
& + \alpha \left\lVert\omega - \mathbf{a}_{t:t+H} - f^a_\theta(\mathbf{a}^{\tau, \omega}_{t:t+H}, \mathbf{o}_t, \ell)\right\rVert^2 \Big], \tag{1}
\end{aligned}
{{< /katex >}}

여기서 {{< katex >}}H(x_{1:M}, y^\ell_{1:M}){{< /katex >}}는 텍스트 토큰과 예측 로짓 사이의 교차 엔트로피 손실이다(FAST로 인코딩된 행동 토큰도 포함된다). {{< katex >}}y^a_{1:H} = f^a_\theta(\mathbf{a}^{\tau, \omega}_{t:t+H}, \mathbf{o}_t, \ell){{< /katex >}}는 (더 작은) 행동 전문가의 출력이고, {{< katex >}}\alpha\in\mathbb{R}{{< /katex >}}는 두 항의 균형을 정하는 파라미터다. 이 방식에서는 먼저 행동을 텍스트 토큰으로 바꿔({{< katex >}}\alpha=0{{< /katex >}}) 모델을 표준 VLM 트랜스포머처럼 사전 학습할 수 있다. 그다음 사후 학습 단계에서 행동 전문가 가중치를 추가한다. 행동 전문가는 연속 행동 토큰을 비자기회귀 방식으로(한 번에) 예측하므로 추론이 빨라진다. 아래에서 더 설명할 이 절차를 따르면 사전 학습이 안정적이고, VLA 모델의 언어 지시 수행 능력도 뛰어나다는 것을 확인했다. 추론 시에는 텍스트 토큰 {{< katex >}}\hat{\ell}{{< /katex >}}을 표준 자기회귀 디코딩으로 만든 뒤, 이 텍스트 토큰을 조건으로 {{< katex >}}10{{< /katex >}}번의 디노이징 단계를 거쳐 행동 {{< katex >}}\mathbf{a}_{t:t+H}{{< /katex >}}를 만든다.

> **역주.** 식 (1)의 {{< katex >}}H(\cdot,\cdot){{< /katex >}}는 교차 엔트로피 함수이고, 같은 식의 아래첨자 {{< katex >}}t+H{{< /katex >}}나 {{< katex >}}y^a_{1:H}{{< /katex >}}의 {{< katex >}}H{{< /katex >}}는 행동 청크 길이다. 같은 글자가 두 뜻으로 쓰였다. 첫째 항은 텍스트와 FAST 행동 토큰의 다음 토큰 예측 손실이고, 둘째 항은 행동 전문가의 플로 매칭 회귀 손실이다. 사전 학습 때는 {{< katex >}}\alpha=0{{< /katex >}}으로 둘째 항을 끄고, 사후 학습 때는 {{< katex >}}\alpha=10.0{{< /katex >}}으로 켠다(4.4절).

### 4.3 Pre-training

첫 번째 학습 단계에서 {{< katex >}}\pi_{0.5}{{< /katex >}}는 폭넓은 로봇 데이터와 비로봇 데이터로 학습된다. 아래에 요약했고 그림 4에도 나와 있다. 이 단계에서 모델은 표준 자기회귀 트랜스포머로 학습되어, 텍스트, 물체 위치, FAST로 인코딩된 행동 토큰의 다음 토큰을 예측한다.

**Diverse *M*obile *M*anipulator data (MM).** 약 100곳의 서로 다른 가정 환경에서 모바일 매니퓰레이터가 가사 작업을 수행한 약 400시간의 데이터를 쓴다. 그중 일부 환경은 그림 7에 나와 있으며, 사용한 로봇은 4.5절에서 설명한다. 학습 데이터 중 이 부분이 평가 작업과 가장 직접 관련된다. 평가 작업도 새롭고 처음 보는 가정 환경에서 이와 비슷한 청소·정리 작업을 하는 것이기 때문이다.

**Diverse *M*ulti-*E*nvironment non-mobile robot data (ME).** 이동하지 않는 로봇의 데이터도 다양한 가정 환경에서 모았다. 팔이 하나인 것도 있고 둘인 것도 있다. 이 팔들은 표면이나 거치대에 고정되어 있다. 훨씬 가볍고 옮기기 쉬워서, 이 로봇들로 더 많은 집에서 더 다양한 데이터를 모을 수 있었다. 다만 이 ME 데이터는 모바일 로봇과는 다른 로봇 형태에서 나온 것이다.

**Cross-*E*mbodiment laboratory data (CE).** 실험실에서 더 단순한 탁상 환경과 여러 종류의 로봇으로 다양한 작업(예: 식탁 치우기, 셔츠 개기)의 데이터를 모았다. 이 중 일부 작업은 평가와 아주 관련이 깊고(예: 그릇을 통에 넣기), 일부는 그렇지 않다(예: 커피콩 갈기). 이 데이터에는 팔이 하나인 매니퓰레이터와 둘인 매니퓰레이터, 고정 베이스와 이동 베이스가 모두 포함된다. 오픈소스 OXE 데이터셋(Collaboration et al., 2023)도 포함한다. 이 데이터셋은 {{< katex >}}\pi_0{{< /katex >}}(Black et al., 2024)가 쓴 데이터셋을 확장한 버전이다.

**High-*L*evel subtask prediction (HL).** 「침실 청소하기」 같은 상위 수준 작업 명령을 「이불 정돈하기」, 「베개 집기」 같은 짧은 하위 작업으로 쪼갤 수 있다. 이렇게 쪼개 두면 학습된 정책이 현재 장면을 추론하고 다음 행동을 더 잘 정하는 데 도움이 될 수 있다. 언어 모델의 사고의 연쇄 프롬프팅과 비슷한 효과다. MM, ME, CE 로봇 데이터 중 작업이 여러 하위 작업으로 이루어진 경우, 모든 데이터에 하위 작업의 의미 설명을 사람이 직접 주석으로 단다. 그리고 {{< katex >}}\pi_{0.5}{{< /katex >}}가 현재 관측과 상위 수준 명령을 바탕으로 하위 작업 레이블(텍스트)과 행동(하위 작업 레이블을 조건으로)을 함께 예측하도록 학습한다. 그러면 자연스럽게 하나의 모델이 상위 수준 정책(하위 작업 출력)과, 그 하위 작업의 행동을 실행하는 저수준 정책 역할을 모두 하게 된다. 현재 관측에 보이는 관련 물체의 바운딩 박스도 레이블링하고, {{< katex >}}\pi_{0.5}{{< /katex >}}가 하위 작업을 예측하기 전에 이를 먼저 예측하도록 학습한다.

**Multi-modal *W*eb *D*ata (WD).** 마지막으로 사전 학습에 다양한 웹 데이터를 포함한다. 이미지 캡셔닝(CapsFusion (Yu et al., 2024), COCO (Chen et al., 2015)), 질의응답(Cambrian-7M (Tong et al., 2024), PixMo (Deitke et al., 2024), VQAv2 (Goyal et al., 2017)), 물체 위치 찾기 데이터다. 물체 위치 찾기에서는 표준 데이터셋에 더해, 실내 장면과 가정용품에 바운딩 박스 주석이 달린 웹 데이터를 추가로 넣어 확장했다.

모든 행동 데이터에서 모델은 목표 관절 자세와 엔드 이펙터(end-effector, 팔 끝의 그리퍼) 자세를 예측하도록 학습된다. 둘을 구분하기 위해 텍스트 프롬프트에 '{{< katex >}}<{{< /katex >}}control\_mode{{< katex >}}>{{< /katex >}} joint/end effector {{< katex >}}<{{< /katex >}}control\_mode{{< katex >}}>{{< /katex >}}'를 덧붙인다. 모든 행동 데이터는 각 데이터셋에서 행동 차원별 1% 및 99% 분위수를 써서 {{< katex >}}[-1,1]{{< /katex >}}로 정규화한다. 행동 {{< katex >}}\mathbf{a}{{< /katex >}}의 차원은 모든 데이터셋 중 가장 큰 행동 공간을 담을 수 있는 고정된 값으로 정한다. 자세·행동 공간의 차원이 더 낮은 로봇은 행동 벡터를 0으로 채운다(zero-padding).

### 4.4 Post-training

이산 토큰으로 280k 그래디언트 스텝 동안 사전 학습한 뒤, 사후 학습이라고 부르는 두 번째 학습 단계를 수행한다. 이 단계의 목적은 두 가지다. 하나는 모델을 본 논문의 사용 사례(가정에서의 모바일 조작)에 특화하는 것이고, 다른 하나는 플로 매칭으로 연속 행동 청크를 만드는 행동 전문가를 추가하는 것이다. 이 단계에서는 텍스트 예측 능력을 유지하기 위한 다음 토큰 예측과, 행동 전문가를 위한 플로 매칭을 함께 학습한다(행동 전문가는 사후 학습 시작 시 무작위 가중치로 초기화된다). 식 (1)의 목적 함수를 {{< katex >}}\alpha = 10.0{{< /katex >}}으로 추가 80k 스텝 동안 최적화한다. 사후 학습의 행동 데이터셋은 MM과 ME 로봇 데이터로 이루어지며, 성공한 에피소드 중 길이가 정해진 임계값보다 짧은 것만 걸러 쓴다. 모델의 의미·시각 능력을 유지하기 위해 웹 데이터(WD)를 포함한다. HL 데이터 중에서는 다중 환경 데이터셋(MM, ME)에 해당하는 부분을 포함한다. 또한 적절한 상위 수준 하위 작업을 예측하는 능력을 높이기 위해 *구두 지시(verbal instruction)* 시연(VI)을 수집한다. 이는 숙련된 사용자가 「언어 시연」을 하는 방식으로 만든다. 즉 사용자가 적절한 하위 작업 명령을 골라 로봇이 모바일 조작 작업을 한 단계씩 수행하도록 지시한다. 이 예제를 모을 때는 사람이 실시간으로 하위 작업 명령을 말해 로봇을 「원격 조종」하고, 이미 학습된 저수준 정책이 그 명령대로 작업을 수행한다. 사실상 학습된 정책에게 좋은 상위 수준 하위 작업 출력이 무엇인지 시연해 주는 셈이다.

**그림 5.** **로봇 시스템 개요.** 모바일 매니퓰레이터 플랫폼 두 종류를 쓴다. 각각 카메라 4대(앞, 뒤, 양쪽 손목), 평행 집게형 그리퍼가 달린 6자유도(DoF) 팔 2개, 이동 베이스, 몸통 리프트 장치가 있다. {{< katex >}}\pi_{0.5}{{< /katex >}} 모델은 각 팔의 관절과 그리퍼, 베이스 속도, 리프트 위치를 제어하며, 그 결과 상태·행동 공간은 18\~19자유도가 된다.

### 4.5 Robot system details

모바일 조작 실험에 쓴 로봇 시스템은 그림 5에 나와 있다. 모든 실험을 두 종류의 모바일 매니퓰레이터로 수행했다. 두 플랫폼 모두 평행 집게형 그리퍼와 손목 장착 단안 RGB 카메라가 달린 6자유도 팔 2개, 바퀴 달린 전방향(holonomic) 베이스, 몸통 리프트 장치를 갖추고 있다. 베이스의 상태·행동 공간은 선속도(2D)와 각속도(1D)이고, 몸통 리프트 장치는 1D(위/아래) 또는 2D(위/아래와 앞/뒤)다. 두 손목 카메라 외에도, 두 팔 사이에 앞쪽과 뒤쪽을 향한 카메라가 하나씩 달려 있다. 상위 수준 추론에는 카메라 4대를 모두 쓰고, 저수준 추론에는 손목 카메라와 앞쪽 카메라를 쓴다. 상태·행동 공간의 전체 차원은 플랫폼에 따라 18 또는 19다.

제어 시스템은 매우 단순하다. {{< katex >}}\pi_{0.5}{{< /katex >}} 모델이 팔, 그리퍼, 몸통 리프트의 목표 자세와 베이스의 목표 속도를 50 Hz로 직접 명령한다(행동 청킹 사용). 이 목표값은 추가적인 궤적 계획이나 충돌 감지 없이 단순한 PD 제어기로 추종된다. 모든 조작과 이동 제어는 완전히 종단간으로 이루어진다.

> **역주.** *PD 제어기*는 목표값과 현재값의 차이(비례, P)와 그 변화율(미분, D)에 비례하는 힘을 내 목표를 따라가게 하는 가장 기본적인 피드백 제어기다. *전방향 베이스*는 몸체를 돌리지 않고도 앞뒤·좌우 어느 방향으로든 바로 움직일 수 있는 바퀴 구성이다.

### 5.2 How does generalization scale with the number of scenes?

다음 실험에서는 학습 데이터에서 본 환경의 수에 따라 일반화가 어떻게 달라지는지 측정한다. 모바일 조작 데이터에 들어간 환경의 수를 바꿔 가며, 3, 12, 22, 53, 82, 104곳의 데이터로 학습해 일반화에 미치는 영향을 측정한다. 각 데이터셋마다 사전 학습과 사후 학습 레시피 전체를 적용하는 것은 연산 비용이 지나치게 크다. 그래서 이 실험에서는 사전 학습을 한 번만 한다. 사전 학습에는 모바일 조작 데이터를 *뺀* 로봇 행동 예측 데이터 혼합을 쓴다. 그다음 환경 수가 서로 다른 모바일 조작 데이터로 각각 사후 학습한 모델들을 비교한다. 위치 수에 따라 나눈 데이터셋은 원칙적으로 크기가 다르다. 하지만 실제로는 학습 스텝 수(40k)를 조정해, 각 모델이 보는 고유 데이터 샘플 수가 같아지게 했다. 이렇게 하면 사후 학습 실험에서 위치 수를 바꿀 때 데이터셋 크기의 영향을 통제할 수 있다.

각 모델은 학습 중 보지 못한 그림 6의 모의 환경에서 평가한다. 평가는 두 종류다. 첫째, 다단계 작업 전체에서 성능이 어떤지 보기 위해 부록 A.2의 표준 기준표와 모의 테스트 가정을 쓴다. 이를 써서 싱크대에 그릇 넣기, 서랍에 물건 넣기, 빨래 정리하기, 침대 정리하기의 종단간 성능을 평가한다. 둘째, 각 모델이 언어 지시를 따르고 새로운 물체를 다루는 능력을 더 세밀하게 평가한다. 이 평가에서 로봇은 언어 명령에 따라 주방 조리대에서 특정 물체를 집어야 한다. 이 실험에는 학습 데이터와 비슷한 범주의 분포 내(in-distribution) 물체(단, 새로운 개체)와, 처음 보는 범주의 분포 밖(out-of-distribution) 물체를 모두 쓴다. 후자는 폭넓은 의미 일반화가 필요하다.

**그림 8.** **학습 위치 수에 따른 성능 평가.** 네 가지 테스트 작업(「싱크대에 그릇 넣기」, 「서랍에 물건 넣기」, 「빨래 바구니」, 「침대 정리」)의 성능은 학습 환경이 많을수록 좋아진다. 녹색 점선과 녹색 막대는 테스트 가정을 학습 데이터에 포함한 기준선 모델이다. 가장 좋은 모델은 테스트 가정의 데이터를 전혀 보지 않았는데도 이 모델과 비슷한 성능을 낸다.

첫 번째 실험의 결과는 그림 8에 있다. 작업 평균 성능은 대체로 학습 위치가 많을수록 좋아진다. 최종 모델(104곳)이 일반화 격차를 얼마나 메우는지 정량화하기 위해, 테스트 가정의 데이터로 직접 학습한 대조군(녹색)을 포함했다. 이 대조군은 104곳으로 학습한 최종 모델과 비슷한 성능을 보인다. 이는 본 공동 학습 레시피가 폭넓은 일반화를 효과적으로 가능하게 해서, 테스트 환경에서 학습한 모델과 비슷한 성능에 도달함을 시사한다. 이 일반화 성능에 전체 공동 학습 레시피가 필요한지 확인하기 위해, 기준선 두 개를 추가로 포함했다. 이 기준선들은 사전 학습 단계에서 다른 공동 학습 작업을 *전혀 쓰지 않고*, 테스트 환경의 데이터(연녹색) 또는 104곳 학습 위치의 모바일 조작 데이터(연노란색)로 바로 학습한다. 두 기준선 모두 성능이 크게 떨어진다. 이는 전체 학습 레시피가 활용하는 다른 데이터 출처가 좋은 일반화에 필수적임을 보여 준다. 정책이 테스트 가정의 로봇 데이터를 본 경우에도 그렇다. 테스트 가정의 데이터를 쓰지 않을 때는 본 레시피로 사전 학습하는 것이 특히 중요하다. 그림 8에서 녹색 막대들과 연노란색 막대 사이의 큰 차이가 이를 보여 준다.

> **역주.** 본문은 「녹색 막대들」이 정확히 어떤 막대를 가리키는지 따로 설명하지 않는다. 앞 문장의 녹색 대조군은 테스트 가정 데이터로 학습한 모델이다. 위치 수별로 학습한 주 모델들의 막대 색은 본문에 나오지 않으므로, 막대와 모델의 대응은 그림 8에서 직접 확인해야 한다.

### 5.3 How important is each part of our co-training recipe?

질문 **(3)**\ 을 살펴보기 위해, 전체 {{< katex >}}\pi_{0.5}{{< /katex >}} 모델을 다른 학습 혼합과 비교해 각 혼합 요소의 중요성을 알아본다. 이번에도 모의 가정에서의 종단간 작업 성능과 5.2절에서 설명한 언어 지시 수행 평가를 쓴다. 다시 정리하면, 전체 레시피는 여러 환경의 모바일 매니퓰레이터 데이터(MM), 여러 환경의 고정형 매니퓰레이터 데이터(ME), 실험실에서 모은 다양한 교차 형태 데이터(CE)를 쓴다. 또한 예측 대상이 상위 수준 언어 명령인 상위 수준 데이터(HL), 그리고 캡셔닝, VQA, 물체 위치 찾기 작업에 해당하는 웹 데이터(WD)를 포함한다. 사후 학습에서는 구두 지시 데이터(VI)도 쓰는데, 이는 5.5절에서 분석한다. 이 실험에서는 혼합의 여러 부분을 하나씩 빼 본다(ablation).

> **역주.** 4.3절에서는 실험실 데이터(CE)만 「교차 형태(cross-embodiment)」라는 이름을 달았지만, 이 절과 그림 10·11·16에서 원문은 ME와 CE를 함께 「교차 형태 데이터」라고 부른다. 둘 다 대상 모바일 매니퓰레이터와 형태가 다른 로봇에서 왔기 때문이다.

1. **no WD**: 웹 데이터를 뺀다.
2. **no ME**: 다중 환경 고정형 로봇 데이터를 뺀다.
3. **no CE**: 실험실 교차 형태 데이터를 뺀다.
4. **no ME or CE**: 다른 로봇에서 온 두 데이터 출처를 모두 뺀다. 이 경우 모델은 대상 모바일 매니퓰레이터 플랫폼의 데이터와 웹 데이터로만 학습된다.

**그림 11.** **학습 레시피 제거 실험, 언어 지시 수행.** 서로 다른 수의 위치로 학습한 뒤, 분포 내 물체와 분포 밖 물체에 대한 언어 지시 수행을 평가한다. 웹 데이터(WD)를 포함하는 것은 특히 분포 밖(OOD) 성능에 중요하다. 교차 형태(CE) 데이터와 다양한 환경(ME) 데이터는 모두 분포 내·분포 밖 성능에 큰 영향을 준다.

전체 모의 가정 작업의 결과는 그림 10에 있다(작업별 세부 성능은 부록 A.4). 먼저 다른 로봇에서 온 두 교차 형태 데이터 출처(ME와 CE) 중 *어느 하나*만 빼도 성능이 크게 떨어진다. 이는 {{< katex >}}\pi_{0.5}{{< /katex >}}가 다른 환경(ME)과 다른 작업(CE) 양쪽에서 오는 교차 형태 전이로 큰 이득을 본다는 뜻이다. 두 출처를 모두 빼면 성능이 더 나빠진다. 눈여겨볼 점은 이 실험에서 **no WD** 제거 실험의 성능 차이가 통계적으로 유의하지 않다는 것이다. 다만 뒤에서 보이듯 웹 데이터는 언어 지시 수행(아래)과 상위 수준 하위 작업 추론(5.5절)에 큰 영향을 준다.

그림 11의 언어 지시 수행 실험 결과도 그림 10과 비슷한 경향을 보인다. ME 및/또는 CE 데이터를 빼면 성능이 크게 떨어진다. 이번에 다른 점은 웹 데이터를 빼면(**no WD**) 분포 밖(OOD) 물체에서 성능이 크게 나빠진다는 것이다. 저자들은 물리적 물체에 관한 매우 폭넓은 지식이 담긴 웹 데이터로 학습하면, 모델이 *처음 보는* 물체 범주가 등장하는 언어 명령도 이해하고 따를 수 있게 된다고 추측한다.

> **역주.** 여기서 원문은 「확산(diffusion)」이라고 썼지만, 식 (1)의 연속 행동 항은 플로 매칭 손실이다. 플로 매칭은 확산 모델과 같은 계열의 기법이라 원문이 두 말을 섞어 쓴 것으로 보인다.

### 5.5 How important is high-level inference?

마지막으로 상위 수준 추론의 중요성을 평가하고, 몇 가지 대안적 상위 수준 추론 방법의 성능을 비교한다. {{< katex >}}\pi_{0.5}{{< /katex >}}의 상위 수준 추론 장치는 상위 수준 명령(예: 「clean the bedroom」)을 받아 수행할 하위 작업(예: 「pick up pillow」)을 출력한다. 이 하위 작업은 사고의 연쇄 추론(Wei et al., 2022)과 비슷하게, 저수준 행동을 추론할 때 맥락으로 쓰인다. {{< katex >}}\pi_{0.5}{{< /katex >}}는 *같은* 모델이 상위 수준과 저수준 추론을 모두 하는 통합 구조를 쓴다. 비교를 위해 상위 수준 부분을 바꾼 기준선 방법을 만들 수 있다. 하나는 표준 VLA 모델에서 흔하듯(Zitkovich et al., 2023; Black et al., 2024) 상위 수준 추론을 생략하고 작업 프롬프트를 저수준 시스템에 바로 넣는 것이다. 다른 하나는 상위 수준 추론에 다른 모델을 써서, 데이터셋의 각 요소가 상위 수준 정책에 미치는 영향을 알아보는 것이다. 다음 방법과 제거 실험을 고려한다. 모두 {{< katex >}}\pi_{0.5}{{< /katex >}}의 저수준 추론 과정 전체를 그대로 쓰고, 상위 수준 정책만 바꾼다.

1. 상위 수준과 저수준 추론 모두에 {{< katex >}}\pi_{0.5}{{< /katex >}} 모델을 쓴다.
2. **no WD**: 웹 데이터를 뺀 {{< katex >}}\pi_{0.5}{{< /katex >}} 제거 실험.
3. **no VI**: 구두 지시(VI) 데이터를 뺀 {{< katex >}}\pi_{0.5}{{< /katex >}} 제거 실험.
4. **implicit HL**: 실행 시 상위 수준 추론은 하지 않지만, 학습에는 상위 수준 데이터를 포함한다. 그러면 모델이 하위 작업에 대해 암묵적으로 배울 수 있다.
5. **no HL**: 상위 수준 추론을 하지 않고, 학습에도 상위 수준 데이터를 전혀 쓰지 않는다.
6. **GPT-4**: GPT-4를 상위 수준 정책으로 쓴다. 상위 수준 정책을 로봇 데이터로 학습하는 것이 얼마나 중요한지 평가하기 위해서다. 모델을 본 논문의 도메인에 맞추기 위해, GPT-4에 두 가지를 프롬프트로 준다. 하나는 작업 설명이고, 다른 하나는 가장 많이 쓰인 하위 작업 레이블 목록이다. GPT-4는 이 목록에서 하나를 고른다.
7. **human HL**: 숙련된 사람을 「오라클」 상위 수준 정책으로 써서 성능 상한을 제공한다.

**그림 13.** **상위 수준 추론 과정 평가.** 상위 수준과 저수준 추론을 모두 하는 전체 {{< katex >}}\pi_{0.5}{{< /katex >}} 모델이 가장 좋은 결과를 낸다. 전체 {{< katex >}}\pi_{0.5}{{< /katex >}} 모델로 저수준 추론만 하는 경우(「implicit HL」)도 학습에 상위 수준 하위 작업 예제를 포함한 덕을 본다. 반면 구두 지시(no VI)나 웹 데이터(no WD)를 빼면 성능이 크게 떨어지고, API 기반 대형 모델(GPT-4)을 제로샷으로 프롬프팅하면 성능이 더 나쁘다.

이 실험의 결과는 그림 13에 있다. 전체 {{< katex >}}\pi_{0.5}{{< /katex >}} 모델이 가장 좋은 성능을 보이며, **human HL** 「오라클」 기준선보다도 낫다. 다소 의외로, 두 번째로 좋은 모델은 **implicit HL** 제거 실험이다. 이 모델은 상위 수준 추론을 전혀 하지 *않지만*, 학습에는 전체 데이터 혼합, 즉 하위 작업 예측까지 포함한다. 이는 본 모델이 쓰는 공동 학습 레시피가 중요함을 강하게 시사한다. 상위 수준 하위 작업을 명시적으로 추론하는 데에도 이득이 있지만, 그 이득의 상당 부분은 학습 혼합에 하위 작업 *예측* 데이터를 넣는 것만으로 이미 얻어진다. 학습에서도 HL 작업을 뺀 **no HL** 제거 실험은 성능이 크게 떨어진다. 결과는 또한 비교적 작은 구두 지시 데이터셋이 높은 성능에 결정적임을 보여 준다. 이 데이터는 상위 수준 모바일 조작 예제의 약 11%에 불과하지만, **no VI** 제거 실험은 성능이 크게 낮다. **no WD** 제거 실험도 크게 나쁘다. 이는 웹 데이터 이득의 상당 부분이 (어쩌면 당연하게도) 상위 수준 정책을 개선하는 데 있음을 뜻한다. 마지막으로 제로샷 **GPT-4** 제거 실험이 가장 낮은 성능을 보이며, 이는 VLM을 로봇 데이터로 적응시키는 것이 중요함을 보여 준다. 작업별 세부 성능은 부록 A.4의 그림 17에 있다.

> **역주.** 그림 13의 막대 위 p값은 각 변형과 전체 {{< katex >}}\pi_{0.5}{{< /katex >}}의 차이에 대한 양측 t-검정 결과다(부록 A.2). implicit HL만 p=0.144로 0.05보다 커서 차이가 통계적으로 유의하지 않다. 따라서 「두 번째로 좋다」는 서술은 전체 모델과의 차이가 통계적으로 뚜렷하지 않은 상태에서의 순위다.

## 6 Discussion and Future Work

본 논문은 {{< katex >}}\pi_0{{< /katex >}} VLA를 바탕으로 만든 공동 학습 모델 {{< katex >}}\pi_{0.5}{{< /katex >}}를 소개했다. 이 모델은 다양한 데이터 출처를 통합해 새로운 환경으로 일반화한다. {{< katex >}}\pi_{0.5}{{< /katex >}} VLA는 모바일 매니퓰레이터를 제어해 학습 데이터에서 한 번도 보지 못한 집에서 작업을 수행할 수 있다. 주방과 침실을 청소하고, 침대를 정리하고, 수건을 걸고, 그 밖의 다단계·고난도 손동작을 수행한다. {{< katex >}}\pi_{0.5}{{< /katex >}}는 약 400시간의 모바일 조작 데이터로 학습되지만, 다른 로봇의 데이터를 훨씬 더 많이 포함한다. 여기에는 다양한 환경의 고정형 매니퓰레이터 데이터와 실험실 조건에서 모은 데이터가 포함된다. 또한 웹 데이터, 그리고 로봇 관측을 바탕으로 언어 명령을 출력하는 상위 수준 예측 데이터와 함께 공동 학습된다. {{< katex >}}\pi_{0.5}{{< /katex >}}의 일반화 능력은 이 공동 학습 레시피가 효과적인 전이를 돕는다는 것을 보여 준다. 그 덕분에 중간 규모의 모바일 조작 데이터셋만으로도 일반화 능력이 높은 모바일 매니퓰레이터 제어가 가능하다.

{{< katex >}}\pi_{0.5}{{< /katex >}}에도 한계는 있다. 이 VLA는 폭넓은 일반화를 보이지만 여전히 실수를 한다. 어떤 환경은 계속 어려움을 준다(예: 낯선 서랍 손잡이, 로봇이 물리적으로 열기 어려운 찬장). 어떤 행동은 부분 관측성(partial observability, 필요한 정보가 관측에 다 보이지 않는 상황) 때문에 어렵다(예: 닦아야 할 얼룩을 로봇 팔이 가리는 경우). 또 어떤 경우에는 상위 수준 하위 작업 추론이 쉽게 산만해진다(예: 물건을 넣다가 서랍을 여러 번 닫았다 열었다 하는 경우). 더 나은 공동 학습, 전이, 더 큰 데이터셋으로 이런 문제를 해결하는 것은 유망한 향후 연구 방향이다. 다른 향후 연구는 이 방법의 기술적 제약을 다룰 수 있다. {{< katex >}}\pi_{0.5}{{< /katex >}}는 주방과 침실을 청소하는 다양한 행동을 수행할 수 있지만, 비교적 단순한 프롬프트만 처리한다. 모델이 감당할 수 있는 프롬프트의 복잡도는 학습 데이터가 정한다. 사람 레이블러를 쓰든 합성으로 만들든, 더 정교하고 다양한 주석을 만들면 더 복잡한 선호와 지시도 반영할 수 있을 것이다. 모델은 또한 비교적 짧은 맥락을 쓴다. 더 풍부한 맥락과 메모리를 넣으면, 다른 방들 사이를 이동하거나 물건을 어디에 두었는지 기억해야 하는 작업처럼 부분 관측성이 더 큰 상황에서 모델이 훨씬 유능해질 수 있다. 더 넓게 보면, {{< katex >}}\pi_{0.5}{{< /katex >}}는 이질적인 데이터 출처의 특정 조합 하나를 탐구한 것이며, 구체적인 데이터 출처는 훨씬 더 폭넓게 탐구할 수 있다. 예를 들어 본 시스템이 구두 지시로부터 배울 수 있다는 점은 로봇을 가르치는 강력하고 새로운 지도 신호(supervision modality)를 제공하며, 향후 연구는 이를 포함해 사람이 로봇에게 추가적인 맥락 지식을 제공하는 다른 방법들을 탐구할 수 있다. 저자들은 이 연구가 다양한 현실 세계 환경으로 폭넓게 일반화하는 새로운 세대의 VLA의 기반이 되기를 바란다.

### A.2 Task evaluation rubric

방법을 정량 평가하기 위해, 학습 데이터셋에 포함된 작업 중 네 가지를 골라 엄밀하게 평가했다(단, 평가는 완전히 새로운 장면과 배치에서 했다). 이 중 둘은 주방 정리 작업, 둘은 침실 정리 작업이다. 한 비교 안의 모든 정책은 각 작업에서 같은 물건 세트로 평가했다(물건은 위치마다 달랐다). 평가 장소는 서로 다른 가정 3곳과, 모의 주방 3곳, 모의 침실 3곳이다(서로 다른 위치 총 12곳). 따로 명시하지 않으면 각 평가와 각 정책마다 작업당 10회 평가한다. 평가 에피소드 하나가 몇 분씩 걸릴 수 있어 시간이 많이 든다는 점에 유의하라. 결과는 각 평가 기준표(아래 참조)에서 얻은 점수가 총점에서 차지하는 비율로 나타낸다. 작업별 지표를 보이거나, 한 비교 안의 모든 정책에 대해 일정한 네 곳의 서로 다른 위치에서 모든 작업을 평균한 지표를 보인다. 따라서 표준 평가에서는 정책당 총 {{< katex >}}40{{< /katex >}}회 평가한다.

> **역주.** 바로 앞에서 평가 위치는 총 12곳이라고 했고, 여기서는 「네 곳」을 평균한다고 한다. 한 비교 안에서는 작업 네 개가 각각 정해진 한 곳에서 평가되는 것으로 읽힌다. 그러면 정책당 작업 4개 × 10회 = 40회가 된다. 본문은 이 대응을 따로 설명하지 않는다. 환경 변화의 영향을 통제하기 위해 정책들을 번갈아 실행하며 평가했다. 일부 평가에는 로봇 고장, 시간 제한 등의 이유로 취소된 에피소드가 있으며, 이는 제외했다. 모든 경우 표본 크기가 비슷하도록 통제했다. 다만 한 그래프 안에서도 정책마다 시도 횟수가 다를 수 있으므로, 이를 허용하는 양측 t-검정으로 통계적 유의성을 보고한다. 언어 지시 수행 평가는 본문에서 설명한 대로 다른 프로토콜을 따른다.

주방 정리 작업(싱크대에 그릇 넣기, 서랍에 물건 넣기)의 평가 지표는 다음과 같다.

- *Dishes in Sink:* 싱크대 근처에 식기 4개(예: 접시, 그릇, 도마, 식기구)가 놓인 상태에서 시작한다. 로봇의 목표는 모두 싱크대에 넣는 것이다.
  - +1: 물건 하나를 집을 때마다.
  - +1: 물건 하나를 싱크대에 넣을 때마다.

  *최고 점수: 8점.*
- *Items in Drawer:* 조리대 위에 물건 하나가 놓인 상태에서 시작한다. 로봇은 이 물건을 조리대 아래 서랍에 넣어야 한다.
  - +1: 물건 집기.
  - +1: 서랍 열기.
  - +1: 물건을 서랍에 넣기.
  - +1: 서랍 닫기(물건이 안에 있을 때).

  *최고 점수: 4점.*

다음은 침실 정리 작업(빨래 정리하기, 침대 정리하기)의 평가 지표다.

- *Laundry in Basket:* 옷 한 벌이 바닥에 놓인 상태에서 시작한다. 로봇의 목표는 빨래를 집어 빨래 바구니에 넣는 것이다.
  - +1: 옷까지 이동해 집기.
  - +1: 옷을 빨래 바구니 안이나 위에 놓기.
  - +1: 옷이 바구니 안에 완전히 들어감.

  *최고 점수: 3점.*
- *Make the Bed:* 침대가 정리되지 않은 상태에서 시작한다. 로봇은 이불을 정돈하고 베개 두 개를 침대 머리 쪽에 놓아야 한다.
  - +1: 이불을 펴서 시트를 덮기.
  - +1: 베개 하나를 침대 머리 쪽에 놓기.
  - +1: 두 번째 베개를 침대 머리 쪽에 놓기.
  - +1: 이불이 매우 깔끔하게 펴짐.
  - +1: 두 베개가 모두 매우 깔끔하게 놓임.

  *최고 점수: 5점.*

### A.3 Language following experiment setup

언어 지시 수행 실험은 처음 보는 주방 장면 두 곳을 써서, 모델이 *「put the scissors in the drawer」*\ 나 *「put the cutting board into the sink」*\ 처럼 더 구체적인 사용자 명령을 얼마나 잘 따르는지 시험한다. 매 시도에서 로봇은 지시를 해석하고, 방해 물체들 사이에서 올바른 물체를 찾아, 작업을 수행해야 한다. 두 시나리오에서 평가한다.

1. **Items in the drawer:** 흔한 주방용품(집게, 나무 서빙 스푼, 캔 따개, 가위, 작은 노란 머스터드).
2. **Items in the sink:** 흔한 식기류(컵, 그릇, 접시, 플라스틱 숟가락, 도마).

매 시도에서 로봇 앞에는 물체 다섯 개가 놓이고, 그중 하나를 옮기라는 지시를 받는다. 지름길 행동을 막기 위해 목표 물체는 방해 물체들보다 더 멀리 놓는다. 그래서 명령을 해석하지 못하는 정책은 언어 지시 수행 정확도가 {{< katex >}}\sim{{< /katex >}}20%에 그쳐야 한다. 두 시나리오에 대해 평균한 두 지표를 보고한다. **언어 지시 수행률(language following rate)**\ 은 올바른 물체를 골랐는지를 측정하고, **작업 성공률(task success rate)**\ 은 그 물체를 지정된 위치에 성공적으로 놓았는지를 평가한다. 또한 서로 다른 학습 환경의 수가 처음 보는 물체로 일반화하는 능력에 어떤 영향을 주는지 살펴본다. 이를 위해 새로운 가정용품(깔때기, 약병, 그릴 점화기, 라이터, 보안경)으로 비슷한 **Items in the drawer** 작업을 설계했다. 이 물체 범주는 모두 학습 데이터에 없었으므로, 이 작업은 분포 밖 물체에 대한 로봇의 성능을 시험한다. 각 작업의 초기 장면 예시는 그림 14에 있다.

### A.5 Model technical details

{{< katex >}}\pi_{0.5}{{< /katex >}} 모델은 {{< katex >}}\pi_0{{< /katex >}}를 기반으로 하며, 시각-언어 이해를 위한 백본으로 PaliGemma VLM(Beyer et al., 2024)을 쓰고, 빠른 행동 생성을 위한 「행동 전문가」를 함께 쓴다. VLM 백본은 {{< katex >}}\pi_0{{< /katex >}}처럼 이미지 시퀀스 {{< katex >}}[\mathbf{I}^1_t, \dots, \mathbf{I}^n_t]{{< /katex >}}와 언어 프롬프트 {{< katex >}}\ell{{< /katex >}}을 받는다. 여기에 더해 로봇의 고유 감각 상태 {{< katex >}}q_t{{< /katex >}}를 토큰화된 형태로 받고, 자기회귀로 예측할 토큰화된 행동(Pertsch et al., 2025)도 받는다. 행동 전문가는 더 작은 트랜스포머다. 입력은 노이즈 섞인 행동 토큰 시퀀스 {{< katex >}}\mathbf{a}_{t:t+H}^{\tau,\omega}{{< /katex >}}이며, 행동 지평(horizon)은 50, 즉 {{< katex >}}H=49{{< /katex >}}다. 행동 전문가는 플로 매칭 목적 함수로 학습된다. 노이즈 섞인 행동 청크(행동 차원 {{< katex >}}d{{< /katex >}})는 먼저 선형 레이어 하나로 트랜스포머 임베딩 차원에 사영된다. {{< katex >}}\pi_0{{< /katex >}}는 플로 매칭 타임스텝 {{< katex >}}\tau{{< /katex >}}를 트랜스포머에 넣기 전에 노이즈 섞인 행동과 합쳤다. 반면 {{< katex >}}\pi_{0.5}{{< /katex >}}는 {{< katex >}}\tau{{< /katex >}}만 사영하는 별도의 MLP를 쓴다. 그리고 적응형 RMSNorm(adaptive RMSNorm)으로 행동 전문가의 각 레이어에 타임스텝 정보를 주입한다. 타임스텝 MLP는 {{< katex >}}\mathrm{swish}(W_2 \cdot \mathrm{swish} (W_1 \cdot \phi(\tau))){{< /katex >}} 꼴이다. 여기서 {{< katex >}}\phi : \mathbb{R} \to \mathbb{R}^w{{< /katex >}}는 사인파 위치 인코딩 함수(Vaswani et al., 2017)이고 {{< katex >}}W_1, W_2 \in \mathbb{R}^{w \times w}{{< /katex >}}다. 행동 전문가는 행동 토큰 {{< katex >}}y^a_{1:H}{{< /katex >}}를 출력하고, 이는 마지막 선형 사영으로 목표 벡터장으로 디코딩된다.

> **역주.** 청크 {{< katex >}}\mathbf{a}_{t:t+H}{{< /katex >}}는 {{< katex >}}t{{< /katex >}}와 {{< katex >}}t+H{{< /katex >}}를 모두 포함하므로 행동이 {{< katex >}}H+1{{< /katex >}}개다. 그래서 행동 50개짜리 청크에서 {{< katex >}}H=49{{< /katex >}}가 된다. *적응형 RMSNorm*은 정규화 레이어의 스케일(과 시프트) 값을 고정 파라미터 대신 조건 입력(여기서는 {{< katex >}}\tau{{< /katex >}}의 임베딩)으로부터 계산해, 조건 정보를 각 레이어에 주입하는 방식이다.

두 트랜스포머의 차원은 {{< katex >}}\pi_0{{< /katex >}}와 같다. PaliGemma 가중치로 초기화한 2B VLM은 {*width*=2048, *depth*=18, *mlp\_dim*=16,384, *num\_heads*=18, *num\_kv\_heads*=1, *head\_dim*=256}이고, 3억(300M) 파라미터의 행동 전문가는 {*width*=1024, *mlp\_dim*=4096}만 다르고 나머지는 같다.

VLM과 행동 전문가의 임베딩은 셀프 어텐션을 통해서만 상호작용한다. 이미지, 프롬프트 토큰, 고유 감각 상태에는 전체 prefix 마스크를 쓴다(이들끼리는 서로 모두 볼 수 있다). FAST 행동 토큰은 이 prefix에 어텐션하고, 이전 행동 토큰에는 자기회귀 방식으로 어텐션한다. 행동 전문가의 임베딩은 prefix, 그리고 행동 전문가 임베딩끼리 어텐션하지만, FAST 행동 토큰에는 어텐션하지 않는다. 두 가지 행동 표현 사이에 정보가 새지 않게 하기 위해서다. 결과적으로 정보는 VLM에서 행동 전문가로 한 방향으로만 흐르며, 어떤 VLM 임베딩도 행동 전문가에 어텐션하지 않는다. 각 레이어의 어텐션 마스크 예시는 그림 18에 있다.

> **역주.** 만약 행동 전문가가 FAST 행동 토큰을 볼 수 있다면, 학습 때 정답 행동이 이미 토큰으로 들어 있으므로 플로 매칭 쪽이 그 답을 베끼는 지름길을 배울 수 있다. 「정보 누출」을 막는다는 것은 이를 차단한다는 뜻이다.

**그림 18.** {{< katex >}}\pi_{0.5}{{< /katex >}} 어텐션 마스킹 패턴의 예.

플로 매칭 타임스텝 {{< katex >}}\tau{{< /katex >}}의 샘플링은 {{< katex >}}\pi_0{{< /katex >}}를 따른다. 요약하면 표준적인 균등 샘플링 {{< katex >}}\tau \sim \mathcal{U}(0, 1){{< /katex >}}(Lipman et al., 2022; Liu, 2022)이나 중간 범위 타임스텝을 강조하는 방법(Esser et al., 2024) 대신, 낮은 타임스텝을 강조하는 샘플링 분포(Black et al., 2024)를 쓴다. 이 분포는 {{< katex >}}p(\tau) = \mathrm{Beta}(\frac{s-\tau}{s}; \alpha=1.5, \beta=1){{< /katex >}}이다. 임계값 {{< katex >}}s{{< /katex >}}보다 큰 타임스텝은 샘플링에서 제외한다. 적분 스텝 크기 {{< katex >}}\delta{{< /katex >}}가 {{< katex >}}\delta > 1-s{{< /katex >}}를 만족하면 그런 타임스텝은 필요 없기 때문이다. 실험에서는 {{< katex >}}s = 0.999{{< /katex >}}를 쓰며, 이는 최대 1,000번의 적분 스텝({{< katex >}}\delta > 0.001{{< /katex >}})을 허용한다.

> **역주.** 여기의 {{< katex >}}\alpha=1.5{{< /katex >}}, {{< katex >}}\beta=1{{< /katex >}}은 Beta 분포의 모양 파라미터로, 식 (1)의 손실 가중치 {{< katex >}}\alpha{{< /katex >}}(사후 학습에서 10.0)와는 다른 값이다. 「낮은 타임스텝을 강조한다」는 서술은 {{< katex >}}\pi_0{{< /katex >}} 논문의 시간 규약을 따른 것인데, {{< katex >}}\pi_0{{< /katex >}}에서는 {{< katex >}}\tau=1{{< /katex >}} 쪽이 노이즈다. 4.2절의 보간식 {{< katex >}}\tau \mathbf{a} + (1-\tau)\omega{{< /katex >}}는 반대 규약({{< katex >}}\tau=0{{< /katex >}}이 노이즈)으로 적혀 있으며, 본문은 두 규약의 관계를 따로 설명하지 않는다.

모든 입력 이미지에 이미지 증강(무작위 자르기, 크기 조정, 회전, 색상 변화)을 다음 하이퍼파라미터와 순서로 적용한다.

transforms = [

    augmax.ColorJitter(brightness=0.3, contrast=0.4, saturation=0.5),
